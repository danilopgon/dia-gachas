## 79. Criterio de modernización

Cada refactor debe mejorar al menos una de:

```text
simplicidad
accesibilidad
tipado
testabilidad
performance
ownership
mantenibilidad
dependency footprint
```

Si la única explicación es:

> “esta API es nueva”.

No se hace.
